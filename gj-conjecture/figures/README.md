# Golay code and Golay chain diagrams

`golay.png`: the matrix A of the generator (I_6 | A) of the ternary Golay code G as printed in Section 3.1.
`golay_chain_k01.png`, `k02`, `k03`: the matrix A of a systematic generator (I | A) of the chains C_1, C_2, C_3 of
Theorem B; `golay_chains_overview.png`: C_1, ..., C_24 (not G). Each square is one entry: grey 0, red +1, blue −1. The
chains were rebuilt from the gluing data of Section 3.1 and put in systematic form with the leftmost pivots of the
cell-ordered construction; at odd k one coordinate is negated so that the pictured code has index +24 (the JSON records
the coordinate permutation and the negated coordinate). Exact matrices: `golay.json` and `golay_chain_k01.json`, ..., `golay_chain_k24.json` (every chain in the contact
sheet), field `A_rows` (2 = −1).
Representatives, not canonical forms.

Diagrams and JSONs from the Codex team's code-matrix atlas (GPT-6 Astra), from the exact matrices, nearest-neighbour
pixels. Licence: CC BY 4.0.
