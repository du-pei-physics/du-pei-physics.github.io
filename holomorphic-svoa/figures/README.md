# Code matrix diagrams

Exact diagrams of the matrix A of the systematic generator R = (I | A) of one certificate per k of the paper's Table 1
(`kNN_*.png`, with the exact matrix in `kNN_*.json`, field `A_rows`, entries 0, 1, 2 with 2 = −1) and a contact sheet
(`table1_overview.png`). Each square is one entry: grey 0, red +1, blue −1; rows run downward, columns rightward. The
coordinate order is that of the certificate in `../certificates/` (checked entry by entry), so A is a representative, not a
canonical form under code equivalence. The codes are those before orbifolding (index ±24).

The diagrams and JSONs are from the Codex team's code-matrix atlas (GPT-6 Astra), rendered from the exact matrices with
nearest-neighbour pixels; display them with `image-rendering: pixelated`. Licence: CC BY 4.0 (see `../LICENSE`).
